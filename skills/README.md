# Standalone skills

One folder per skill, each with a `SKILL.md` at its root (YAML frontmatter with `name` and `description`, then the instructions), plus optional `scripts/`, `references/` and `assets/` folders. This is the Agent Skills format read by Claude (claude.ai, Claude Code, Cowork), OpenAI Codex, Cursor, GitHub Copilot and others.

Install one skill by copying its folder into your tool's skills directory, or download its zip from the Releases page. See the root README for the paths per tool.
